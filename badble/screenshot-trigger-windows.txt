REM ===================================================================
REM screenshot-trigger-windows.txt  -  press the M5 button => 1 screenshot
REM   on the PAIRED Windows target (Bad-BLE HID keyboard).
REM   Authorized LOCAL LAB use only (your own device / written permission).
REM
REM HOW IT WORKS
REM   The M5 advertises as a BLE keyboard ("Keyboard_xxxxx"). Pair it from
REM   the target, keep the target UNLOCKED, then each WAIT_FOR_BUTTON_PRESS
REM   below pauses until you press the M5 (front/Select) button - and then
REM   the screenshot hotkey is sent. So: 1 M5 press = 1 screenshot.
REM   This file gives 20 triggered captures, then ends - relaunch for more.
REM   Press the side/power button to abort the run.
REM
REM TARGET: Windows
REM   Hotkey: GUI PRINTSCREEN
REM   (Win+PrtScn -> auto-saves a full-screen PNG to Pictures\Screenshots.)
REM   Fallback: If PRINTSCREEN does nothing on your build, swap the SCREENSHOT
REM   lines to:  GUI-SHIFT s   (Win+Shift+S snip toolbar - guaranteed keys).
REM
REM PLATFORM REALITY (classic ESP32, BLE 4.2)
REM   Windows / Linux / macOS pair as a BLE keyboard  -> this works.
REM   iPhone / iPad will NOT enumerate the keyboard    -> not supported.
REM   Android pairs, but its screenshot is Power+VolDown (PHYSICAL keys),
REM     with no standard hardware-keyboard shortcut     -> use a PC target.
REM ===================================================================
