REM ===================================================================
REM screenshot-trigger-android.txt  -  press the M5 button => 1 screenshot
REM   on the PAIRED Android (14+) target (Bad-BLE HID keyboard).
REM   Authorized LOCAL LAB use only (your own device / written permission).
REM
REM HOW IT WORKS
REM   The M5 advertises as a BLE keyboard ("Keyboard_xxxxx"). Pair it from
REM   the target, keep the target UNLOCKED, then each WAIT_FOR_BUTTON_PRESS
REM   below pauses until you press the M5 (front/Select) button - and then
REM   the screenshot hotkey is sent. So: 1 M5 press = 1 screenshot.
REM   This file gives 20 triggered captures, then ends - relaunch for more.
REM   Press the side/power button to abort the run.
REM
REM TARGET: Android (14+)
REM   Hotkey: GUI s   (GUI = the Meta / Search key)
REM   (Search+S -> system screenshot saved to Pictures/Screenshots (Android 14+).)
REM   Fallback: Needs Android 14+ (Search+S shortcut). The Search key = Meta = GUI.
REM   No Search+S? Pre-Android-14 / some OEM skins have NO keyboard screenshot
REM   key at all (it is Power+Vol-Down, physical) - then use Assistant instead:
REM   summon Assistant, type 'take a screenshot', ENTER (device-dependent).
REM
REM PLATFORM REALITY (classic ESP32, BLE 4.2)
REM   Android pairs as a BLE keyboard -> works on Android 14+ via Search+S.
REM   Pre-14 / some OEM skins expose NO keyboard screenshot key (physical
REM     Power+Vol-Down only) -> use the Assistant fallback above, or a PC.
REM   iPhone / iPad will NOT enumerate the keyboard at all -> not supported.
REM ===================================================================
